# SWYNEX Final Delivery Pipeline

## Project Overview
This project demonstrates a Continuous Integration (CI) pipeline using Python, pytest, and GitHub Actions.

## Objectives
- Develop a simple Python application.
- Write automated tests using pytest.
- Configure GitHub Actions to run tests automatically on pushes and pull requests.
- Verify the pipeline using successful workflow runs.

## Technologies Used
- Python
- pytest
- Git and GitHub
- GitHub Actions
- YAML

## Pipeline Workflow
1. Code is pushed to the main branch.
2. GitHub Actions checks out the repository.
3. Python 3.12 is configured.
4. pytest is installed.
5. Automated tests are executed.
6. The workflow reports success or failure.

## Validation
The CI workflow completed successfully, with a green check mark confirming that the automated test passed.

## Project Outcome
This project demonstrates basic CI automation, automated testing, version control, and pipeline validation.
